# CashFlow

A web application for managing your finances. It allows you to keep track of your transactions, accounts, and tags. You can also generate reports and graphs to help you understand your spending habits.

Developed by Diego Faria as an open-source portfolio project.

## Features

- Keep track of your transactions
- Keep track of your accounts
- Keep track of your tags
- Generate reports
- Generate graphs
- Multi-currency support
- User authentication and authorization

## Installation

1. Clone the repository
2. Install the dependencies with `pip install -r requirements.txt`
3. Run the migrations with `python manage.py migrate`
4. Start the server with `python manage.py runserver`

## Usage

1. Open a web browser and go to `http://127.0.0.1:8000/`
2. Log in  or sign in with your username and password
3. Add your accounts, transactions, and tags
4. Generate graphs, reports and keep feeding the system for useful financial feedback!

## Development

1. Clone the repository
2. Install the dependencies with `pip install -r requirements.txt`
3. Make changes to the code
4. Run the migrations with `python manage.py migrate`
5. Start the server with `python manage.py runserver`
6. Open a web browser and go to `http://localhost:8000/`
